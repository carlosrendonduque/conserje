Conserje demo page

A stand-in for a client landing page. The widget in the corner is the real one, talking to a real backend.

Before this works

  1. Build the widget: node --run build in widget/.
  2. Put your key in backend/.env.
  3. Start the API: php -S localhost:8000 -t backend/public.
  4. Serve this page: node widget/serve-demo.mjs.

Why port 8080

sites/carlosrendon.json lists the origins allowed to embed this site. Open this page on any other port and the backend will refuse the request with a 403 — that is the allowlist working, not a bug. Add your origin to the config to change it.
